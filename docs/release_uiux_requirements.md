### 1.2. Статусы

- **Согласовано** — решение или текст подтверждены в переписке. Это не означает, что оно уже реализовано.
- **Согласовано с проверкой** — направление принято; публикация утверждений зависит от проверки реального процесса.
- **Редакционная сборка** — дословные утверждённые фрагменты объединены с последующими явно принятыми поправками. Изменения перечислены у соответствующего текста.
- **Не утверждено / проверить** — гипотеза, недостающая точная формулировка или незавершённый вопрос; не превращать автоматически в обязательную разработку.
- **Отменено / заменено** — ранний вариант, который не должен определять реализацию.

Приоритеты сохранены по смыслу исходного аудита: Critical — подтверждённый сбой оформления покупки; High — существенно для коммерческой готовности; Medium — улучшение понятности и согласованности; Low — полировка. Реестр использует новые стабильные ID R01–R55: старые UX-ID в обсуждении иногда повторно использовались для разных тем. Например, UX-LAND-06 обозначал проверку шрифта, затем разделение консультаций; UX-CHECK-03 менял смысл; UX-REF-03 в разных файлах означал контактные данные и проверку возвратов. При разработке ориентироваться на название и стабильный ID настоящего документа.

### 1.3. Границы аудита

Аудит касался публичного customer journey и коммерческой подачи. Исходный backend/release-readiness remediation описан в переписке как завершённый; dedicated public visual/UI/UX review оставался следующим pre-deployment gate. Финальные workbook и Walkthrough RU/EN считались готовыми; отдельный Product Description исключён из обязательного комплекта.

Проверялись прежде всего desktop-скриншоты и доступный текст страниц. Review-среда https://smartbudget-review.neocitrix.com работала read-only: публичные GET/HEAD доступны, Admin/API/download/booking ограничены, POST checkout заблокирован. Реальные покупки и оплаты в этом review не проводились. Полный mobile/accessibility review был отложен до обновления desktop с учётом мобильных ограничений уже при проектировании.

Настоящая работа восстанавливает решения; она не проверяет текущий main, настройки Calendly, доставку почты, реальные возвраты или актуальное законодательство. Исторические сведения о коде и праве ниже фиксируются как результаты прежнего обсуждения, а не как новая независимая проверка.

## R47 — ActiveX onboarding and customer guidance

Record the following accepted product/UX direction.

SmartBudget is an Excel-based application using VBA and ActiveX functionality, including the Excel `WebBrowser` component.

Current supported release target remains:

- Windows 10/11;
- desktop Microsoft Excel 2019 or later, including Microsoft 365 for Windows;
- VBA must be available to enable;
- required ActiveX functionality must be available to enable;
- Excel for macOS is unsupported;
- Excel for the web is unsupported.

SmartBudget now includes an ActiveX availability diagnostic/startup guard.

Expected product behavior:
